## Выводы

### 1. Vulkan на 780M — включать

Prefill быстрее в ~1.4–1.6×, генерация в ~2.2–3.8×. Для пайплайна ZakupCheck это снимает главный риск «медленный инференс на CPU».

### 2. Для MVP: Q5_K_M + `-ngl 99`

- на Vulkan лучший prefill (268 t/s);
- генерация почти как у Q4 (14.2 vs 15.4 t/s);
- по карточке модели качество заметно выше Q4 (Ru Arena Hard 78.6 vs 71.7);
- Q6 почти не даёт прироста prefill и заметно медленнее в генерации (11.9 t/s).

### 3. Роли остальных квантизаций

| Квант | Решение |
| --- | --- |
| Q5_K_M | **основная** для MVP |
| Q4_K_M | точка сравнения «качество / скорость» в eval |
| Q6_K | опционально, только если понадобится эталон качества |

### 4. Закрытие открытого вопроса дизайна (§13 п. 2)

- Q5_K_M vs Q6_K → **Q5_K_M по умолчанию**
- Vulkan на 780M → **да, прирост подтверждён**
- инференс MVP: `llama-server` + T-lite-it-2.1 Q5_K_M, `-ngl 99`
